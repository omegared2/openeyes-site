# OpenEyes — Site oficial (versão inicial)

Site estático responsivo em HTML, CSS e JavaScript para GitHub Pages. Não contém checkout, login, downloads fictícios ou credenciais.

## Publicação no GitHub

1. Entre em https://github.com/new com sua conta `omegared2`.
2. Nome do repositório: `openeyes-site`. Marque **Public** e clique **Create repository**.
3. Clique em **uploading an existing file** ou **Add file > Upload files**.
4. Extraia este ZIP e envie os arquivos `index.html`, `style.css`, `script.js` e `README.md` **para a raiz do repositório** (não envie a pasta inteira como subpasta).
5. Clique **Commit changes**.
6. Abra **Settings > Pages**. Em **Build and deployment**, escolha **Deploy from a branch**; branch **main**, pasta **/(root)**; clique **Save**.
7. Aguarde a publicação e visite https://omegared2.github.io/openeyes-site/.
