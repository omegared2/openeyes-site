# OpenEyes — atualização visual v2

Site estático para GitHub Pages com identidade visual aprovada: olho cibernético azul neon, cards Games, IA, Anime, Apps e Store.

## Instalar usando GitHub Desktop (Windows)

1. Extraia o ZIP.
2. No GitHub Desktop, abra o repositório `omegared2/openeyes-site`.
3. Clique em **Repository > Show in Explorer**.
4. Copie **o conteúdo desta pasta** (`index.html`, `style.css`, `script.js`, `README.md` e pasta `assets`) para dentro da pasta do repositório. **Não copie a pasta OpenEyes_Atualizacao_v2 inteira.**
5. Confirme a substituição dos arquivos antigos.
6. No GitHub Desktop, escreva `Atualização visual OpenEyes v2` no Summary, clique em **Commit to main** e depois **Push origin**.
7. Aguarde o GitHub Pages atualizar: https://omegared2.github.io/openeyes-site/ . Se necessário, pressione Ctrl+F5.

## Observações

- Site promocional: os botões de pagamento e downloads ainda não foram integrados.
- Os cartões usam imagens derivadas da arte visual aprovada.
- A imagem aprovada era um mockup com textos desenhados; o site usa recortes para evitar menus e textos duplicados e recria os elementos como HTML acessível.
